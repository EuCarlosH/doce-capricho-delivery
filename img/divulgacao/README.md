# Imagens de divulgação

Esta pasta é o local oficial para imagens usadas em avisos, promoções e divulgações cadastradas no painel administrativo.

## Padrão para novos arquivos

- Use nomes descritivos em letras minúsculas.
- Separe palavras com hífen.
- Não use espaços, acentos ou caracteres especiais.
- Prefira WebP para arquivos menores.
- Use PNG quando a arte precisar de transparência ou quando for necessário preservar esse formato.
- Sempre valide a URL pública depois da publicação.

## Formato da URL

`https://docecaprichoatelier.vercel.app/img/divulgacao/nome-do-arquivo.ext`

Os arquivos antigos mantidos diretamente em `img/` continuam disponíveis apenas para não quebrar divulgações já cadastradas.
